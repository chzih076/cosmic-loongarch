# 性能基线（PERFORMANCE）

LoongArch 单核性能有限，"好用"必须有**客观数字**兜底。本文件规定**测量方法**、**基线表**与**回归判定**。

## 1. 测量方法（可复现）

### 1.1 采集命令

```bash
# 整机负载（1/5/15 分钟）
awk '{print "load:", $1, $2, $3}' /proc/loadavg

# COSMIC 全量进程内存（RSS 合计，MB）
ps -eo comm,rss | grep -i cosmic | awk '{s+=$2; n++} END{printf "cosmic: %d 进程, 内存 %.0f MB\n", n, s/1024}'

# 合成器 CPU 占用（交互场景下采样 5 次）
for i in $(seq 5); do ps -o pcpu= -C cosmic-comp | tr -d ' '; sleep 2; done

# GPU 占用与显存（amdgp）
cat /sys/class/drm/card*/device/gpu_busy_percent
awk '{printf "VRAM %.2f GB\n",$1/1073741824}' /sys/class/drm/card*/device/mem_info_vram_used

# 帧率（在 COSMIC 内运行游戏/视频时用 MangoHud 或应用自带统计）
```

### 1.2 场景定义（每次测试保持一致）

| 场景 | 定义 | 采集时长 |
|---|---|---|
| **S0 空闲** | 仅桌面与面板，无窗口；不触碰鼠标键盘 | 60 s |
| **S1 交互** | 连续拖动一个终端窗口 + 滚动输出 | 60 s |
| **S2 多窗口** | 打开 6 个窗口并自动平铺；切工作区两次 | 60 s |
| **S3 视频** | `cosmic-player` 播放 1080p30 视频 | 120 s |
| **S4 启动** | 从 `start-cosmic` 到面板可交互的耗时 | 单次计时 |

### 1.3 记录格式

每行记录：日期 / 上游 pin / 补丁集版本 / 场景 / CPU%（合成器）/ 内存（COSMIC 合计）/ GPU% / 备注。

## 3. 判定标准

- **退化**：同一场景下，cosmic-comp CPU 或 COSMIC 总内存相对上一版基线恶化 **> 10%**，且排除测量噪声（至少 3 次采样取中位数）；
- 出现退化时：在 `docs/TESTING.md` §3 记录表注明原因（新功能、上游变更、补丁副作用），并在发版说明中披露；
- 参考对照：社区评测普遍指出 COSMIC **内存占用偏高**，本仓库以"不劣化"为目标，不承诺优于其它桌面。

## 4. 已知影响因素

| 因素 | 影响 |
|---|---|
| 从 TTY 启动会话 | 可能继承 KDE 环境变量（K-005），对性能无直接影响，但会影响应用行为 |
| `cosmic-files-applet` | 桌面图标管理，偶发 15–20% CPU（K-004/K-007），会拉高 S0 数字 |
| 合成器多节点导入失败（K-003） | 偶发重复合成/花屏，可能推高 GPU 与 CPU |
| 缩放/多输出 | 高分辨率或分数缩放显著增加合成开销，测试时固定为 `2560x1440@100%` |
| 动画补丁（计划 0001） | 关闭动画会降低合成器负载，属于**预期**的性能变化，需在基线中标注当前设置 |
